# Happy Zoo

Zoo website

🔗 **Live Demo:** (https://zoo-ten-lemon.vercel.app/)

---


## ✨ Features

- Four pages: Home, Animals, Employees, and Test




---

## 🛠️ Technologies Used

- **React** — frontend framework (components, pages, styles)
- **React Router** — page navigation
- **Custom CSS** — color palette and styling
- Deployed on **Vercel**

---

## 🚀 Setup Instructions

To run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/khaledkarhani/zoo.git

# 2. Move into the project folder
cd zoo

# 3. Install dependencies
npm install

# 4. Start the development server
npm start
```

The app will open at `http://localhost:3000`.
